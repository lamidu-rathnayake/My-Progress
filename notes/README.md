# Notes Guide

Create a topic note when you actually study, recording the source, your explanation, an example, independent practice, mistakes and review status. No learning notes have been invented during repository organization.

| Topic | Destination when needed |
|---|---|
| Current Probability & Statistics | `notes/mathematics/probability-statistics/` |
| Parallel arithmetic, algebra, functions and essential trigonometry | `notes/mathematics/algebra-foundations/` |
| Vectors, matrices and later linear algebra | `notes/mathematics/linear-algebra/` |
| Calculus | `notes/mathematics/calculus/` |
| Programming concepts | `notes/programming/` |

Create each folder with its first real note. Use descriptive kebab-case names such as `sample-spaces-and-events.md` or `functions-and-graphs.md`; these are naming examples, not completed topics. Keep one topic per note and add useful related links sparingly.

Follow **Concept → Notes → Worked Example → Independent Practice → Review**. Record sources and assumptions, use your own explanation, and retain mistakes and corrections. Keep executable exercises in [labs](../labs/) and link actual evidence from [Progress](../PROGRESS.md).

The detailed [mathematics plan](../MATHEMATICS.md) owns the topic checklist. Avoid copying it into each note. Keep private university source files outside this public repository unless sharing is permitted; never copy employer data or secrets here.

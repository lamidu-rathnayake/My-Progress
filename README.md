## 🛠️ Learning Approach

I follow a practical, understanding-focused learning process:

1. **Learn** — Understand the concepts and underlying principles.
2. **Practise** — Solve problems and complete small exercises independently.
3. **Build** — Apply knowledge through projects and university coursework.
4. **Verify** — Test solutions, identify mistakes, and improve them.
5. **Document** — Record useful insights, challenges, and learning progress.

A topic is considered complete when I can explain it clearly and apply it to an unfamiliar problem—not simply after finishing a tutorial.

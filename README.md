## Keep it maintainable

After studying, save a short topic note and spend two to five minutes recording evidence in the progress journal. Watching a video is not proof of understanding. The existing HTML/CSS files remain useful learning material; no topic mastery is inferred from file presence. University exercises count toward roadmap topics, so repeat only demonstrated gaps.

Keep large applications in separate repositories. Exclude datasets, model weights, passwords, tokens, production configurations, and proprietary banking or employer information. Use synthetic examples for work-related learning.

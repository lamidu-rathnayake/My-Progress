# Web Foundations Labs

Existing small HTML/CSS exercises are preserved as learning evidence, not proof of current mastery. Open each HTML file in a browser; these static exercises need no package installation.

| Exercise | Learning objective |
|---|---|
| [HTML track configuration](<01 html/Track Config Panel/index.html>) | Semantic structure, forms, labels, images and tables |
| [Styled track configuration](<02 css/Track Config Panel/index.html>) | CSS variables, form styling and flex layout |
| [Flex track header](<02 css/flex/index.html>) | Align controls with Flexbox and adapt layout for narrow screens |
| [Grid workspace starter](<02 css/grid/index.html>) | Explore page regions and eventually implement a CSS Grid layout |

The grid exercise is a starter: its stylesheet is not linked and does not yet define a grid. Both configuration exercises contain a `#help` link with no matching target. These existing exercise gaps are recorded for later practice; the original code is unchanged.

After revisiting an exercise, record what you changed and can explain in [Progress](../../PROGRESS.md). Keep future labs small, with a clear objective and simple run instructions. Large applications belong in dedicated repositories.
